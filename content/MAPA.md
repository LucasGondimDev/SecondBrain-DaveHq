# MAPA — Content

## Estrutura

```
content/
├── drafts/      → Rascunhos (posts, emails, textos)
└── publicados/ → Conteúdos publicados
```

## Como usar

- Quando gerar um **post** → `content/drafts/post-YYYY-MM-DD.md`
- Quando gerar um **email** → `content/drafts/email-YYYY-MM-DD.md`
- Quando publicar → move para `publicados/`
